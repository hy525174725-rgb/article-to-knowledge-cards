# make-knowledge-cards

把一篇文章提炼成 5~8 张知识卡片的 AI Skill（Agent Skill 格式）。

## 这个项目解决什么问题

读完一篇文章，"看懂了"不等于"记住了"。本项目提供一个 Skill，让 AI 助手把用户粘贴的文章或本地 Markdown/TXT 文件自动提炼成结构化的知识卡片：每张卡片只讲一个知识点，配通俗解释和自测问题，帮助用户快速抓住重点、检验掌握程度。

## 主要功能

- 将粘贴的文章文本或本地 `.md` / `.txt` 文件提炼为 **5~8 张知识卡片**（知识点不足时如实少做，不硬凑数量）
- 每张卡片包含四个字段：**标题、核心知识、简明解释、例子或自测问题**（附参考答案）
- 只提取真正重要的知识：一卡一知识点、自动合并重复内容、按重要性排序
- 忠于原文：不编造原文没有的信息、数据或例子；自测答案可从原文推出
- 输入过短时不做卡，直接提示用户提供更完整的文章
- 明确不支持：网页抓取、PDF 解析、Anki 导出、图形界面

## 安装方法

本仓库是一个 Agent Skill，目录结构如下：

```
skills/make-knowledge-cards/
├── SKILL.md              # Skill 定义（触发描述 + 工作流程）
└── agents/
    └── openai.yaml       # OpenAI 兼容接口声明
```

将整个 `skills/make-knowledge-cards` 目录复制到你的 Agent 的 skills 目录（如 `~/.agents/skills/` 或项目的 `skills/` 目录）即可被自动加载；无需安装任何依赖。

## 使用方法

对 Agent 说出类似请求即可触发：

- "用 make-knowledge-cards 把下面这篇文章转换成知识卡片：……（粘贴文章）"
- "把 `文章.md` 做成知识卡片"（Agent 会用 `read_file` 读取本地文件）

Agent 会执行：通读全文 → 识别候选知识点 → 筛选合并 → 按固定模板生成卡片 → 输出前自检。

## 输入输出示例

**输入**（粘贴的短文）：

> 番茄工作法使用25分钟专注工作加5分钟休息为一个周期，四个周期后休息15~30分钟。它适合需要对抗拖延的任务。

**输出**：

```markdown
### 卡片 1：番茄工作法的基本结构
- **核心知识**：25分钟专注工作+5分钟休息为一个周期，四个周期后休息15~30分钟。
- **简明解释**：短周期让"开始工作"的心理门槛变低，固定休息防止疲劳累积；适合需要对抗拖延的任务。
- **例子/自测**：自测：四个周期后的长休息时长是多少？
——答案：15~30分钟。

（原文信息有限，仅提炼出 1 个独立知识点，未强行凑够 5 张。）
```

更长、知识点充足的文章会产出 5~8 张卡片，例如一篇约 1500 字的科普文（如"大语言模型为什么会幻觉"）可提炼出 6 张卡片：幻觉的定义、根本原因（预测式训练目标）、训练数据遗传错误、RAG 缓解、RLHF 与"学会说不"、幻觉无法根除。
