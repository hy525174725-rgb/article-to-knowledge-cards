# Make Knowledge Cards

将一篇文章（粘贴的文本或本地 `.md` / `.txt` 文件）提炼为 5~8 张知识卡片，帮助用户快速掌握和自测核心内容。

## 输入来源（仅两种）

1. **用户直接粘贴的文章文本** — 直接使用。
2. **本地 Markdown/TXT 文件** — 用 `read_file` 读取后使用。

其他来源（URL 抓取、PDF、Word、图片等）一律拒绝，并说明本 Skill 仅支持上述两种输入。

## 工作流程

### 第 1 步：通读全文，识别候选知识点

通读全文，列出候选知识点。优先提取：
- 文章主旨、核心论点或结论
- 关键概念、定义、原理
- 重要的数据、事实、对比关系
- 方法、步骤、可操作的经验

忽略：寒暄、过渡句、重复表达、与主题无关的旁支内容。

### 第 2 步：筛选与合并

- 一篇文章通常产出 **5~8 张卡片**；知识点不足时**宁缺毋滥**，可以少于 5 张，并在末尾用一句话说明原因（如"原文信息有限，仅提炼出 3 个独立知识点"）。
- 一张卡片只讲**一个**知识点；同一信息在不同段落重复出现时合并为一张。
- 按重要性排序：最核心的知识排前面。

### 第 3 步：生成卡片

每张卡片严格使用以下 Markdown 格式：

```markdown
### 卡片 N：{标题}

- **核心知识**：{一句话点明这个知识点是什么}
- **简明解释**：{2~4 句话，讲清楚"为什么/怎么回事"，只使用原文信息}
- **例子/自测**：{或举一个原文中的例子，或出一道自测问题}——出问题时参考答案固定写成"——答案：{参考答案}"，与问题分行或清晰分隔
```

### 第 4 步：输出前自检

- [ ] 每张卡片都是单一知识点，无重复
- [ ] 所有信息均来自原文，未编造原文没有的内容
- [ ] 解释通俗易懂，没有把原文简单换个说法（要有"为什么"）
- [ ] 卡片数量在合理范围（不足 5 张时已说明原因）

## 硬性规则

1. **不编造**：原文没有的信息、数据、例子一律不写；例子只能取自原文。
2. **不硬凑**：原文支撑不了 5 张卡片时，如实少做。
3. **不拆分**：一个知识点不拆成多张凑数。
4. **仅文本输入**：拒绝网页抓取、PDF、Anki 导出、图形界面等非文本请求。
5. **过短输入兜底**：输入短到无法支撑一张完整卡片（如一两句话）时，不做卡，直接向用户说明并请求更完整的文章。

## 输出示例

输入：一篇介绍"间隔重复"学习法的短文 →

```markdown
### 卡片 1：间隔重复为什么有效

- **核心知识**：分散复习比集中复习更利于长期记忆。
- **简明解释**：大脑在"快要遗忘"时提取信息最费力，这种费力会强化记忆痕迹；集中复习缺少这种提取难度，所以 retention 更差。
- **例子/自测**：自测：为什么考前通宵复习的效果通常不好？
——答案：因为缺少间隔带来的提取练习，记忆未得到强化。
```
